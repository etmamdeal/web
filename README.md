# 🌟 منصة إتمام الصفقة – Etmam Server

Etmam Server هو نظام SaaS متكامل مبني على Python وFlask، يهدف إلى تمكين العقاريين والمسوقين العقاريين من إدارة أعمالهم وصفقاتهم وبياناتهم الرقمية باحترافية وسهولة، مع دعم كامل للغة العربية وتجربة مستخدم عصرية متوافقة مع الهوية البصرية للمنصة.

---

## 🎯 أهداف المنصة

- تقديم خدمات احترافية للعملاء بعد الاشتراك (عروض، صفقات، إدارة بيانات)
- تمكين العملاء من إدارة العقارات والصفقات والعملاء من مكان واحد
- توفير أدوات تسويقية متقدمة (سكربتات، كتب، قواعد بيانات)
- ربط العملاء بموقع خارجي للمنتجات لتخفيف الضغط على النظام الأساسي
- الحفاظ على أنظمة الاشتراكات والتذاكر الفنية وتطويرها دون المساس بها

## 🏆 مميزات الاشتراكات والباقات الجديدة

- **نظام اشتراكات مرن:** يدعم عدة باقات (أساسية، متقدمة، احترافية) مع صلاحيات وميزات متدرجة
- **إدارة الاشتراك:** يمكن للعميل ترقية أو تجديد أو إلغاء اشتراكه من لوحة التحكم
- **تفعيل تلقائي للميزات:** تفعيل الأدوات التسويقية والمنتجات حسب الباقة
- **نظام تذاكر فني متكامل:** دعم فني مباشر عبر التذاكر مع تتبع الحالة والردود
- **إشعارات وتنبيهات:** تنبيهات فورية حول حالة الاشتراك، انتهاء الصلاحية، أو توفر ميزات جديدة

## 🖥️ لوحة تحكم العميل – تجربة متكاملة

- **واجهة عربية بالكامل** مع تصميم عصري وألوان مستوحاة من الشعار (بيج فاتح، أخضر، أزرق بنفسجي)
- **قائمة جانبية تفاعلية** مثبتة يمين الشاشة، مع روابط سريعة لإدارة العقارات، الصفقات، الأدوات التسويقية، التذاكر، والاشتراك
- **إدارة العقارات:** إضافة، تعديل، حذف، واستعراض العقارات مع رفع صور متعددة وعرضها بشكل مصغر وجذاب
- **إدارة الصفقات:** تتبع مراحل الصفقات، إضافة وتعديل الصفقات، ربطها بالعقارات والعملاء
- **إدارة العملاء:** عرض وتعديل بيانات العملاء المرتبطين
- **أدوات تسويقية:** سكربتات، كتب إلكترونية، وقواعد بيانات حسب الباقة
- **نظام تذاكر فني:** فتح تذكرة جديدة، متابعة الردود، وإغلاق التذاكر
- **إدارة الاشتراك:** عرض تفاصيل الباقة، تاريخ الانتهاء، خيارات الترقية والتجديد
- **تجربة مستخدم محسنة:** دعم كامل للجوال، شريط سفلي (footer) ثابت، أزرار واضحة، مؤشرات تحميل، ونوافذ تأكيد للعمليات المهمة

## ⚙️ المواصفات الفنية والتقنية

- **اللغة والإطار:** Python 3.8، Flask 3.0.2
- **قاعدة البيانات:** SQLite مع SQLAlchemy ORM
- **إدارة الهجرات:** Alembic وflask-migrate
- **نظام تسجيل الدخول والصلاحيات:** Flask-Login، Flask-Security-Too، Flask-Principal
- **إرسال البريد:** Flask-Mail مع Zoho SMTP
- **إدارة الجلسات:** JWT وFlask-Login
- **التصميم:** HTML5، CSS3، Bootstrap، خط Questv1-Regular
- **دعم الترجمة:** flask-babel
- **مهام مجدولة وخلفية:** APScheduler، Celery
- **إدارة الكاش:** Flask-Caching
- **إدارة الأخطاء والتصحيح:** Flask-DebugToolbar
- **تطوير واجهات برمجة التطبيقات:** RESTful API موثقة
- **دعم WebSocket:** Flask-SocketIO
- **اختبارات:** اختبارات وحدة وتكامل شاملة للمسارات والنماذج

## 🛠️ المشاكل التي واجهتنا وكيف تم حلها

### 1. مشاكل الهجرات وقاعدة البيانات
- **الوصف:** ظهور خطأ OperationalError بسبب عدم وجود أعمدة جديدة بعد تعديل النماذج.
- **الحل:** إعادة تهيئة Alembic، حذف الهجرات القديمة، إعادة إنشاء قاعدة البيانات، وتطبيق الهجرات من جديد.

### 2. مشاكل المسارات والـ Endpoints
- **الوصف:** أخطاء BuildError عند ربط القوالب بمسارات غير معرفة.
- **الحل:** إضافة جميع المسارات الناقصة في app.py وربطها بالقوالب الصحيحة.

### 3. مشاكل القوالب (Templates)
- **الوصف:** ظهور رموز غريبة (CSRF token) أو متغيرات غير معرفة في القوالب.
- **الحل:** التأكد من تمرير جميع المتغيرات المطلوبة للقوالب، وإخفاء الحقول الحساسة بشكل صحيح.

### 4. مشاكل الأداء وتجربة المستخدم
- **الوصف:** بطء تحميل لوحة التحكم، مشاكل في تحميل الخطوط أو الأنماط.
- **الحل:** دمج الأنماط في base.html، تحسين تحميل الخطوط، واستخدام مؤشرات تحميل وتنبيهات تفاعلية.

### 5. مشاكل البريد الإلكتروني
- **الوصف:** فشل إرسال البريد من بعض النماذج.
- **الحل:** توحيد إعدادات SMTP، تحسين تسجيل الأخطاء، وإضافة رسائل تأكيد للمستخدم.

### 6. مشاكل الصلاحيات وتسجيل الدخول
- **الوصف:** أخطاء في توجيه المستخدمين أو ظهور current_user غير معرف.
- **الحل:** تحديث إعدادات Flask-Login، إضافة context processor لتمرير current_user لجميع القوالب.
